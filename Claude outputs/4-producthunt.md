## Короткое описание (для карточки, ~260 символов)

Wrench-Branch is a workspace of 71 developer & QA tools — JSON, regex, cron, hash, encoding, API tools and more — running client-side in your browser. Pin your favorites into a personal Workbench, and keep your skills sharp with daily QA/dev challenges.

## Полное описание

**The problem:** every dev/QA workflow ends up with the same 5-10 browser tabs open — a random JSON formatter here, an anonymous UUID generator there, never sure who's actually handling the data you paste in.

**What Wrench-Branch does:** one workspace, 71 tools across 10 categories (JSON/YAML, regex, encoding, hashing, cron expressions, API response validation, generators, and more) — most run entirely client-side, nothing leaves your browser.

**Two things that make it more than "just another tool list":**
- **Workbench** — pin your own frequently-used tools into a named, drag-to-reorder workspace. Stop re-bookmarking the same 6 tools.
- **Daily Challenges** — a chess.com-puzzle-style daily task system for QA/dev skills, with streaks and a leaderboard.

A handful of AI-assisted tools too (generate a regex from a plain-English description, generate QA test cases from a user story, JSON → TypeScript).

Free tier covers every tool with no limits. Pro ($5/mo) adds unlimited AI generations, the full challenge archive, and progress stats.

Built solo, tested with a real Playwright E2E suite that's already caught a couple of genuine production bugs along the way.

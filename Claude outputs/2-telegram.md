# Telegram QA-каналы — черновик поста

Важно: в большинстве каналов нельзя просто взять и запостить рекламу своего проекта — это модерируется, где-то есть отдельный день/тред для самопиара, где-то нужно писать админу и договариваться (иногда платно, иногда бесплатно если контент реально полезный). Прежде чем постить:

1. Проверь закреплённые сообщения канала на предмет правил (часто там написано "самопиар — в комментариях" или "по пятницам" и т.п.).
2. Если правил не видно — напиши админу лично, коротко объясни, что сделал бесплатный тулкit для QA и хочешь поделиться, спроси можно ли.
3. Начни с 2-3 каналов, посмотри на реакцию, потом расширяй список — не рассылай одинаковый текст во все каналы одновременно.

## Вариант A — для чатов (более неформальный, "делюсь находкой")

Ребят, привет 👋

Сделал себе (и теперь всем, кому надо) тулкит из 71 инструмента для QA/dev — то, что обычно ищешь по одному на рандомных сайтах: JSON formatter, regex tester, cron expression parser (показывает ближайшие 5 запусков — удобно проверять cron-джобы), API response validator, генераторы UUID/hash, base64/URL кодеры и т.д.

Всё работает прямо в браузере, ничего никуда не улетает. Регистрация не нужна — она нужна только если хочешь сохранить свой набор избранных тулз (Workbench) или участвовать в ежедневных челленджах.

Кстати про челленджи — сделал формат в духе шахматных puzzle с chess.com, только задачки на QA/dev тематику, с streak'ами. Возможно, кому-то как раз для регулярной прокачки скилов.

Ссылка: https://wrench-dev-lr29.vercel.app

Буду рад фидбеку, особенно "а вот такого тула у вас не хватает" — реально собираю такие запросы и добавляю.
